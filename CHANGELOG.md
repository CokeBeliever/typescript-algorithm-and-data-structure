# Changelog

All notable changes to this project will be documented in this file.

The format is inspired by Keep a Changelog, and this project follows Semantic Versioning in spirit.

## [Unreleased]

### Changed

- Enabled `noImplicitAny` and tightened several core type signatures.
- Removed runtime `*.types.js` and `*.types.mjs` build artifacts from `dist/`.
- Added more boundary-focused tests for `Comparator`, `Stack`, and `BinaryTreeNode`.
- Improved project tooling, CI, contribution docs, and package verification flow.
- Switched the project license from ISC to MIT.

## [1.0.0] - 2026-03-30

### Added

- Initial public release with core data structures, graph structures, traversal algorithms, shortest path algorithms, and heuristic helpers.
